REQUEST FOR PROPOSAL #2026-014

Enterprise Knowledge Management and Response Automation Platform

Vendors must review all sections, appendices, amendments, and notices. Information shown on this page may be supplemented without prior email notification.

1. Overview / General Instructions

The selected vendor shall provide a hosted solution for organizing internal capability documents and assisting authorized employees with complex questionnaire responses. Proposals must remain valid for the period stated in Appendix D.

Mandatory Security Controls

Item Ref Requirement Text
SEC-01 The solution must support single sign-on using SAML 2.0 and allow administrators to disable local password authentication.
SEC-02 Customer data must be encrypted in transit using currently supported TLS protocols and encrypted at rest with vendor-managed or customer-managed keys.
SEC-03 The platform shall maintain an exportable audit trail for document access, administrative changes, approval decisions, and final submissions.
SEC-04 Role-based access controls must separate content authors, reviewers, approvers, and system administrators.

TECHNICAL ENVIRONMENT

The proposed service must expose documented HTTPS APIs for approved integrations. The vendor response should describe authentication, pagination, rate-limit handling, and error reporting.

Document Ingestion

Users must be able to ingest PDF, DOCX, HTML, and plain-text reference material. The system should preserve source attribution so reviewers can identify the supporting document for a generated draft.

Human Approval Before Submission: Any workflow that enters responses into the procurement portal must pause before the final submission action. A named, authorized employee must explicitly approve the staged bid before it can be submitted.

Response Quality and Traceability

Each drafted answer shall include references to the internal source material used. Where relevant evidence is unavailable, the system must flag the answer for manual completion rather than creating unsupported claims.

Deployment and Data Location. The proposal must identify available hosting regions, tenant-isolation controls, backup arrangements, and the process for exporting or deleting customer content at contract termination.

Pricing submission notes

Provide implementation fees, recurring subscription charges, optional service fees, and applicable taxes as separate line items. Do not include confidential pricing in the technical response attachment.

Vendor Support

Describe standard support channels, escalation procedures, maintenance communications, and customer responsibilities. Any service commitments must be clearly identified as standard or optional.
