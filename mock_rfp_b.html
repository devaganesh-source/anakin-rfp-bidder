REQUEST FOR PROPOSAL MHN-2026-88

On-Premises Clinical Document Automation Platform

1. Overview / General Instructions

Meridian Health Network seeks software for clinical document workflows across its hospitals. The production system must run inside Meridian-managed data centers rather than in a vendor public cloud.

Mandatory Healthcare Security Controls

Item RefRequirement Text
SEC-01The vendor must demonstrate HIPAA compliance, sign a Business Associate Agreement, and describe safeguards for protected health information.
SEC-02Protected health information must use TLS 1.3 in transit and AES-256 at rest, with customer-managed keys supplied through Azure Key Vault.
SEC-03Provide audit records suitable for HIPAA access investigations, including patient-record views, exports, emergency-access events, and administrator activity.
SEC-04Access controls must separate clinical content authors, reviewers, approvers, and administrators, with a custom permission matrix for each hospital workspace.

TECHNICAL ENVIRONMENT

The complete platform must be deployable on-premises on Meridian-managed Kubernetes clusters with no dependency on a vendor-hosted control plane or public-cloud service.

Document Ingestion

The system must ingest HTML and plain-text policy files and preserve exact source attribution so compliance reviewers can trace each generated answer to its supporting passage.

Human Approval Before Submission: A Meridian procurement employee must review the staged response and explicitly approve it before the mock bid can be submitted.

Response Quality and Traceability

Each generated answer must include an inline citation to internal source material, and unsupported claims must be flagged or routed for manual completion.

Deployment and Data Location. All application services, indexes, backups, telemetry, and encryption keys must remain inside Meridian facilities, including during upgrades and support investigations.

Pricing submission notes

Quote a fixed annual site license for each hospital with unlimited users and documents. Do not propose per-user charges. List appliance, implementation, and optional training fees separately.

Vendor Support

Provide 24/7 ticket and email support, a dedicated customer success manager, a one-hour response commitment for critical issues, and maintenance notice 72 hours in advance.
